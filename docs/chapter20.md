# Inventory

We now have access to many different blocks and terrain types, but we don't have a way to select which one we want to place.
For this, we need some kind of inventory.
For now, we'll implement just a creative mode inventory, where we can select any block type and place it in the world.
We also need a hotbar.

To start, we'll define just the hotbar, with a pre-defined selection of blocks.
